# My-Cv Sikhulile Njowa
Personal CV webpage built with HTML and CSS, deployed via GitHub Pages.

A simple static website acting as my online CV.  
Built with HTML and CSS, styled for a clean and professional look, and deployed using GitHub Pages.

## About
This webpage introduces me to the world, highlighting my education, skills, and experience.  
It also reflects my personality and hobbies, such as exercising and jogging.

## Features
- Personal introduction and contact details
- Skills and competencies
- Education background
- Work and bootcamp experience
- Profile image
- Styled with CSS for a modern layout
